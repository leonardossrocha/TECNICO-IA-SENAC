# UC: Desenvolver Banco de Dados

## Visão Geral
Esta Unidade Curricular capacita os alunos a projetar, implementar e manipular repositórios de dados estruturados. O foco central é garantir a integridade, segurança e disponibilidade dos dados, compreendendo que um banco de dados bem estruturado é o alicerce fundamental para qualquer treinamento e aplicação de Inteligência Artificial.

## Objetivos
- Levantar requisitos e abstrair regras de negócio para a modelagem de dados (Conceitual e Lógica).
- Implementar e gerenciar bancos de dados físicos utilizando SGBDs e linguagem SQL (DDL, DML, DQL).
- Estruturar, higienizar e exportar conjuntos de dados (datasets) orientados a pipelines de Machine Learning.
- Aplicar boas práticas de segurança, governança e conformidade com a LGPD em projetos de dados.

## Conteúdo Programático
- Teoria de Banco de Dados Relacional e Arquitetura de SGBDs
- Modelagem de Dados: Entidade-Relacionamento (MER/DER) e Normalização
- Linguagem SQL: Criação de Estruturas (DDL) e Manipulação de Dados (DML)
- Consultas Complexas, Junções (Joins) e Funções de Agregação (DQL)
- Preparação de Datasets para IA (Formatos CSV, JSON, Parquet)
- Ética de Dados, Viés Algorítmico e Princípios da LGPD

## Metodologia
- Aprendizagem Baseada em Problemas (PBL) com cenários do mercado.
- Aulas práticas em laboratório com ferramentas colaborativas e SGBDs em nuvem/locais.
- Dinâmicas ativas adaptadas para ambiente digital (Pair Design, Coding Dojo e ScrumLite).
- Desenvolvimento progressivo de um projeto integrador com foco em IA.

## Organização do Repositório
- `diagramas/` - arquivos `.drawio` ou imagens png dos modelos lógicos e conceituais.
- `scripts_sql/` - arquivos `.sql` com comandos DDL e DML divididos por atividade.
- `slides/` - links para as apresentações em PDF ou Google Slides.
- `README.md` - guia de navegação da Unidade Curricular.
